# Static Login Page Deployment

A simple and responsive static Login & Signup page built using HTML and CSS and deployed using GitHub Pages.

This project was created to practice frontend UI development, responsive design, and GitHub deployment workflows.

## How to Run Locally

Clone the repository:

```bash
git clone https://github.com/your-username/Amplify-login-page-deployment.git
```

Move into the project directory:

```bash
cd Amplify-login-page-deployment
```

Open the project:

```bash
open index.html
```

or simply double-click `index.html`.

---

## Deployment

This project is deployed using GitHub Pages.

### Steps Used for Deployment

1. Push project to GitHub
2. Open repository settings
3. Navigate to **Pages**
4. Select branch as `main`
5. Save and deploy
